## 灵录 0.3.8

- 云端字幕翻译最多同时处理三批，先完成的译文会立即显示并保存。
- 翻译报错或取消后，已保存的译文会保留。选择同一目标语言，点「继续翻译」即可补齐剩余字幕。
- 模型输出格式不合要求时，只重试出问题的批次。翻译期间修改的原文和手动编辑的译文会保留。

适用于 macOS 13.3+、Apple Silicon。

## English

- Cloud subtitle translation runs up to three batches at a time. Completed translations appear and save as each batch finishes.
- Completed translations stay in the project after an error or cancellation. Choose the same target language and select Continue translation to finish the remaining subtitles.
- The editor retries only the batch with invalid model output and preserves source edits and manual translations made during a run.

Requires macOS 13.3+ on Apple Silicon.
