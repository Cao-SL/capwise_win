## 灵录 0.3.4

- **按 T 添加标题**：在播放头位置创建文字并直接输入。调整文字样式时，输入过的内容会保留。
- **按 ⌘V 贴图**：从剪贴板或访达粘贴图片，图片会保存到工程，随后可拖动、缩放和设置动效。
- **按 R 框选脱敏**：拖出矩形即可添加遮盖。鼠标入口在「标注」菜单，可在时间线调整时长，并在模糊和像素化之间切换。
- **编辑助手和 CLI 支持图层动作**：可添加标题、图片和静态遮盖。助手先给出待确认的修改；CLI 的 `cap project overlay` 支持预览和项目版本校验。

适用于 macOS 13.3+、Apple Silicon。

## English

- Press **T** to add a title at the playhead and type directly on the canvas.
- Press **⌘V** to paste an image from the clipboard or Finder. The project keeps its own copy.
- Press **R** to draw a redaction, or choose the tool from the Annotation menu. Adjust its duration and switch between blur and pixelation.
- The editor assistant and `cap project overlay` can add titles, images and static redactions. Review the assistant's proposed edits or preview a CLI edit with a project revision check.

Requires macOS 13.3+ on Apple Silicon.
