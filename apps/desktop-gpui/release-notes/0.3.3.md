## 灵录 0.3.3

- **插入就能看到**：在片头或片尾添加图片、贴纸、标注、脱敏时，自动定位到正片；贴纸避开入场动画的透明首帧。文字仍可直接添加到封面，默认显示「输入文字」。
- **字幕状态异常可恢复**：修复字幕快照被误当作任务状态导致的导出阻断；异常文件保留备份，并提供明确恢复操作。
- **导出状态更清楚**：保存位置选择失败不再静默改存其他目录；完成与失败各有明确状态，失败可调整设置后重试，完成可直接定位文件。导出页面支持键盘导航。
- **助手方案不丢失**：修改方案时遇到请求失败或停止，会保留原方案；停止后可继续编辑请求，过期方案也有恢复入口。
- **项目库操作更可靠**：键盘可以访问项目和操作按钮，删除或保存失败会显示恢复指引；删除工作流预设前先确认。
- **更容易理解的编辑面板**：封面时长支持快捷选项与精确输入，字幕隐藏会明确说明导出效果，减少重复的主按钮和导航入口。

适用于 macOS 13.3+、Apple Silicon。

## English

- Pictures, stickers, annotations and masks inserted over a title card now appear on the footage. Text can still be added to title cards, with a localized starting label.
- Caption snapshots no longer block exports as malformed task states. Invalid status files are preserved before explicit recovery.
- Clear export success and failure states, explicit save-location errors, retry settings, file reveal and keyboard navigation.
- Assistant refinements preserve the previous plan on failure or cancellation and help recover the request.
- Keyboard-accessible project actions, visible file-operation errors and confirmation before deleting a workflow preset.
- Quick and precise title-card durations, explicit hidden-caption feedback and simpler editor controls.

Requires macOS 13.3+ on Apple Silicon.
