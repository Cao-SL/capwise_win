## 灵录 0.3.7

- 恢复 Mac 安装包内置的 53 张壁纸和缩略图。
- 点开单行字幕时，输入框留在侧栏视野里。「字幕 → 内容 → 编辑全部字幕」可以直接改任意一行、查找替换，或右键删除选中的文字。
- 在「字幕 → 翻译」开启「修改原文后自动重译」，只更新改过且已有译文的句子。
- AI 助手和字幕校对在模型输出未通过校验时，会按具体问题重试。

适用于 macOS 13.3+、Apple Silicon。
